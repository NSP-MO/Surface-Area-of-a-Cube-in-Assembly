# Surface Area of a Cube
Program ini merupakan program sederhana yang berfungsi untuk menghitung luas permukaan kubus berdasarkan panjang sisi yang dimasukkan oleh pengguna. Program ini ditulis menggunakan bahasa Assembly NASM untuk arsitektur x86 pada sistem operasi Linux dan Windows. 


## Compiler yang digunakan:
- **Linux NASM Compiler (OneCompiler):** [OneCompiler NASM](https://onecompiler.com/assembly/3zktug7xu)
- **Windows NASM Compiler (OllyDbg):** [OllyDbg](https://www.ollydbg.de/)
